# AOSP Kernel with KernelSU + SuSFS for Exynos 9611

## Features

- KernelSU Next support
- Backported SuSFS v1.5.12
- WireGuard in-kernel VPN drivers
- Compiled with [WeebX Clang](https://github.com/XSans0/WeebX-Clang) 19.1.5 and LLVM binutils

# ⚠️ Disclaimer ⚠️

- This kernel is **NOT** compatible with OneUI ports or OneUI stock ROMs
- This kernel works with custom ROMs or AOSP-based GSIs from Android 15/16. However, since some older custom ROMs for Exynos 9611 - e.g. [Project Elixir](https://projectelixiros.com) - use [Grass Kernel](https://github.com/Roynas-Android-Playground/kernel_samsung_universal9611), I can't guarantee if this kernel will work with them
- This kernel is **ONLY** for Exynos 9611 devices (A51, F41, M31s, M31, M21 and Tab S6 Lite LTE and Wi-Fi)

### Flashing Instructions

Flash the kernel using custom recovery or via adb sideload
